# MHGC-Net

MHGC-Net is a multi-view audio anti-spoofing and deepfake detection model that integrates acoustic, prosodic, and semantic representations through heterogeneous graph reasoning.

This repository currently provides the core model implementation and its required local modules. The source code, dependency information, and architecture details are available in the [MHGC-Net directory](./MHGC-Net/).

## Code Availability

The complete training and evaluation code will be publicly released upon acceptance of the manuscript.

The current release does not include model weights, training or evaluation pipelines, or datasets.

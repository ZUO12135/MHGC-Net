The core model implementation provided in this repository is the same as that used in the experiments reported in our paper, “MHGC-Net: A Multi-View Heterogeneous Graph Collaborative Attention Network for Robust Audio Deepfake Detection”.

The current release includes the core model implementation and its required local modules. It does not include model weights, training or evaluation pipelines, or datasets. The complete training and evaluation code will be publicly released upon acceptance of the manuscript.
